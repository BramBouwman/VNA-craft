# VNA-Craft plugins

Deze map bevat optionele uitbreidingen voor VNA-Craft.

## Qratio-plugin

`qratio_plugin.py` ondersteunt een begeleide meting van:

1. Qmax unloaded.
2. Qmax loaded.
3. Qratio = gemiddelde unloaded Qmax / gemiddelde loaded Qmax.

De gebruiker bepaalt zelf wanneer elke fase start, stopt of opnieuw wordt gestart. De plugin is optioneel en verandert de standaard Qmax-registratie niet.
